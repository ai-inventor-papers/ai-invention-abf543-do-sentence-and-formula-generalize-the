# FOLIO-Refined

**FOLIO-Refined** is a refined version of the FOLIO dataset
introduced by Han et al. (2024).  
This dataset aims to provide a more reliable benchmark for evaluating
auto-formalization and logical reasoning agents.

We identify and repair label errors and misalignment between nature language (NL) and first-order logic (FOL), while preserving the original premises, conclusions,
and dataset structure.

---

## Dataset Structure

The dataset follows the same split structure as the original FOLIO benchmark:

- `train.csv`
- `validation.csv`

---

## Relationship to the Original FOLIO Dataset

This dataset is a **derivative work** of the FOLIO dataset:

> Han, S., et al. *FOLIO: Natural Language Reasoning with First-Order Logic*. 2024.

We preserve the original license and attribution.
All modifications are limited to FOL and label refinement.
