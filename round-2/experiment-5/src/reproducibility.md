# Reproducibility

- **Environment:** Python 3.12 via uv. Run `bash restore.sh` to rebuild `.venv/`, `raw/pilot/` and `raw/sara/`. The runs used torch 2.14 and z3-solver with `TORCH_DISABLE_NATIVE_JIT=1`, which `src/common.py` sets.
- **Hardware:** 7 CPUs (cgroup limit), 42 GB RAM, and one RTX 4090 used for the local Qwen3-8B back-translation and the DeBERTa/MiniLM scoring.
- **Seeds:**
  - sentence selection and the panel sample use seed 20260924;
  - the bootstrap uses seed 0 with 2,000 draws;
  - cross-fitting uses seeds 100–104;
  - DC random structures use seed 0.
- **Frozen artefacts:**
  - the generation prompt (sha1 `afabb41eedb31b3ee96e32419bd8e4abd727f758`);
  - the B1 prompt (sha1 `d7fe4b542820d08a2489de0c7fcf8b40baa5187d`);
  - the DC config and code sha1s in `results/dc_config.json`, frozen at 2026-09-24T04:42:48Z, before any label was read;
  - vendored code sha1s in `results/frozen_manifest.json`.
- **API calls:** every OpenRouter response is cached in `work/llm_cache.jsonl`, keyed by the sha1 of the request body, so a re-run costs $0 and reproduces the same outputs. Local Qwen3-8B outputs are cached in `work/local_llm/`.
- **Order of execution:** `.venv/bin/python method.py --stages all`. The stage list is at the top of `method.py`.
- **Checks:**
  - `results/unit_tests.json`: 16/20 pass. The 4 failures are documented identifiability limits.
  - `results/audit_rederive.json`: sklearn re-derivation matches within 1e-15.
  - `results/dev_anchor.json`: DC 0.774 vs the round-2 references 0.756–0.787.
- **Known non-reproducible element:** the OpenRouter provider routing and sampled outputs at T=0.8. The cache preserves the realised outputs.
